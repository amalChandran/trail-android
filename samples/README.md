# Journey fixtures and attribution

`journeys.json` is the source of truth for both native playgrounds. Run `python3 scripts/sync-fixtures.py` after editing it; CI rejects stale copies. Coordinates are `[latitude, longitude]`. No directions request is made by the library or during tests.

- **Flight:** approximate JFK (40.6413, −73.7781) and Heathrow (51.4706, −0.461941) airport coordinates. Connections are generated by Trail, not recorded flight tracks. Reference: [OurAirports airport data](https://ourairports.com/data/).
- **Cab:** 119-point full driving-geometry response from the public [OSRM route service](https://project-osrm.org/docs/v5.22.0/api/), captured 19 September 2026, between Times Square (40.7580, −73.9855) and Grand Central (40.7527, −73.9772). Request used `overview=full&geometries=geojson&steps=false`; response longitude/latitude pairs were converted to latitude/longitude. This is a fixed illustrative snapshot, not current turn-by-turn navigation. Route data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under the [Open Database License](https://opendatacommons.org/licenses/odbl/1-0/). Preserve attribution when redistributing this fixture.
- **Ferry:** 13 original, hand-authored waypoints from Circular Quay to Manly around Sydney Harbor headlands. Endpoint context: [Transport for NSW F1](https://transportnsw.info/routes/details/sydney-ferries/f1/090F1). This is an illustration, not an official operator sailing track, navigational chart or timetable. The waypoints are distributed under this repository's license.

Map tiles, labels and imagery are supplied by the active provider under its own terms. The sample retains the native map attribution. Test fixtures contain no user location history or API credentials.
